# AI-Copilot 自動運転支援デモ（オフライン版）

`ai-copilot-demo.html` をブラウザ（Chrome / Edge 推奨）で開くだけで動きます。インストールは不要です。

- 画面：はじめに ／ ① 連携シミュレーター ／ ② 車両システム配置図 ／ ③ データグラビティ
- 3画面はシナリオA〜Eでつながっています。各画面の「Linked」帯で、データの発生 → 前処理 → Copilot提案 → 車両の実行を確認できます。
- 「はじめに」の「通しデモを開始」で、A〜Eを自動再生したあとデータグラビティのツアーへ進みます。
- フォント（Google Fonts）はネット接続時のみ読み込みます。オフラインでは代替フォントで表示されます。
- ナレーションはブラウザの日本語音声を使います。数値・車両・道路はすべて説明用の架空のサンプルです。
